# Personal Portfolio

A minimal, responsive résumé-style portfolio with a blog and AI chat assistant, built with React, TypeScript, Tailwind CSS, and Vite.

## Development

Requires Node.js 20 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm lint
pnpm build
```

The frontend deploys through the repository's GitHub Pages workflow. Convex stores blog view counts, and the Netlify function proxies chat requests.
